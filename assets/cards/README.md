# Card Assets

This directory should contain the SVG playing card graphics.

## Required Files

Download from: https://github.com/htdebeer/SVG-cards

Place the following file in this directory:
- `svg-cards.svg` - The complete deck as a single SVG with named elements

## Alternative: Individual Card Files

If using individual card files, they should be named:
- `heart_1.svg` through `heart_king.svg`
- `diamond_1.svg` through `diamond_king.svg`
- `club_1.svg` through `club_king.svg`
- `spade_1.svg` through `spade_king.svg`
- `back.svg` for card back
