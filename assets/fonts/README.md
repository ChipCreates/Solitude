# Fonts

This directory should contain the Inter font family files.

## Required Files

Download from: https://rsms.me/inter/

Place the following files in this directory:
- `Inter-Regular.ttf`
- `Inter-Medium.ttf`
- `Inter-SemiBold.ttf`
- `Inter-Bold.ttf`
