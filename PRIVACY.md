# Privacy Policy for Solitude

**Last Updated: January 1, 2026**

## Overview

Solitude is a free, open-source solitaire game that respects your privacy. This privacy policy explains how the app handles data.

## Data Collection

**Solitude does NOT collect, transmit, or share any personal information.**

### What Data is Stored Locally

The following data is stored locally on your device only:

1. **Game Progress**
   - Current game state (card positions, move history)
   - Automatically saved when you exit a game mid-play
   - Restored when you return to the app

2. **Game Statistics**
   - Games played, won, and lost (per game variant)
   - Best time and fewest moves records
   - Win streaks
   - Vegas scoring totals (if enabled)

3. **Achievements**
   - Achievement unlock status and timestamps
   - Progress toward achievement goals

4. **Settings & Preferences**
   - Theme selection (colors, card backs)
   - Sound and vibration preferences
   - Game difficulty settings
   - Hint mode preferences
   - Draw mode preferences (Klondike)

### Where Data is Stored

All data is stored locally using:
- **Tauri FS / SQLite** on Desktop & Native targets
- **IndexedDB** on Web & PWA builds
- Storage location: App's private local data directory on your device

### What We DON'T Do

- ❌ No personal information collected
- ❌ No data sent to external servers
- ❌ No analytics or tracking
- ❌ No advertisements
- ❌ No in-app purchases
- ❌ No account creation required
- ❌ No internet connection required
- ❌ No third-party data sharing

## Data Security

Your game data is stored in your device's secure app data directory:
- Only Solitude can access this data
- Data is deleted when you uninstall the app
- No data is synchronized to the cloud

## Data Control

You have full control over your data:

### Resetting Statistics
- Navigate to Settings → Statistics
- Tap "Reset Statistics" to clear all game statistics
- This action cannot be undone

### Clearing Game Data
- Uninstalling the app removes all locally stored data
- On Android/iOS: Standard app uninstall
- On Desktop: Uninstall via OS package manager

## Children's Privacy

Solitude does not collect any data from users of any age. The app is safe for children to use.
